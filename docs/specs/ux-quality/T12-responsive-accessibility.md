# T12 — Responsive and Accessibility Audit

## Objective

Audit and fix completed workflows across desktop, laptop, tablet, mobile, and small mobile.

## Requirements

Review semantic landmarks, keyboard navigation, focus visibility/order, labels/errors, button/link semantics, touch targets, contrast, state communication, overflow, and long content. This is an audit/fix task, not a redesign.
