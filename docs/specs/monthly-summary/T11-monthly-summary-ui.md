# T11 — Monthly Summary UI

## Objective

Present monthly completion information in a calm, compact, understandable secondary UI.

## Requirements

Cover loading, empty, success, error/retry, accessible labels, responsive layout, and long/small-screen behavior. Do not turn Notebook Lab into an analytics dashboard or add charts without a proven need.
